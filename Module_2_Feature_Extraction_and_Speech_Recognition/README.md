## Module Overview & Syllabus Breakdown (7 Lectures)

### Topic 1: Feature Extraction Overview & Cepstral Analysis
- Real Cepstrum and Complex Cepstrum definition
- Mel-Frequency Cepstral Coefficients (MFCC) extraction pipeline
- Linear Prediction Cepstral Coefficients (LPCC)

### Topic 2: Dynamic Features & Vector Quantization
- Delta ($\Delta$) and Delta-Delta ($\Delta\Delta$) feature computation
- Mean and Variance Feature Normalization
- Vector Quantization (VQ) & LBG Clustering Algorithm

### Topic 3: Pattern Matching & HMM-Based Speech Recognition
- Dynamic Time Warping (DTW) pattern matching
- Hidden Markov Models (HMM) topology & evaluation (Forward-Backward, Viterbi algorithms)
- HMM-based Continuous Speech Recognition architectures
